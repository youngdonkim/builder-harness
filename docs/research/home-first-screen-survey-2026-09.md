- 히어로에 제목: 16곳 중 16곳 / 부제: 16곳 중 15곳(Figma 없음)

- 여러 장을 넘기는 히어로: **16곳 중 0곳**
- 상단 공지·프로모션 띠: 한국 8곳 중 6곳, 해외 8곳 중 2곳 (그중 도는 띠는 한국 3곳, 약 2~5초)
- 채팅 상담 버튼: 한국 8곳 중 6곳(레몬베이스는 도움말 단추만), 해외 8곳 중 3곳
- 첫 방문 팝업이 히어로를 덮은 곳: 16곳 중 1곳(그리팅)
- 홈 본문에 가격표 섹션: **16곳 중 0곳** / FAQ 섹션: **16곳 중 0곳** — 가격은 상단 바 링크로만 있음(16곳 중 15곳)
- 푸터 바로 앞 최종 행동 유도 섹션: 16곳 중 14곳 (채널톡·Airtable은 뚜렷하지 않음)
- 로그인 후 관찰: 1곳(Vercel, 히어로 없음) + 참고 1곳(GitHub, 히어로 없음)

### 커뮤니티·SNS (로그인 전 16곳: 한국 8·해외 8, 로그인 후 0곳)

- 한국: 콘텐츠가 바로 보이는 곳 **8곳 중 7곳** (편집형 5·목록형 1·허브형 1), 가입 랜딩 1곳(밴드)
- 해외: 가입을 먼저 요구하는 화면 **8곳 중 6곳** (가입 화면 3: X·Instagram·Quora / 가입 랜딩 3: LinkedIn·Pinterest·Discord), 콘텐츠 옆에 가입 패널 1곳(Reddit), 가입 요구 없이 목록 1곳(Stack Overflow)
- 첫 화면 안 가입·로그인 수단: 한국은 로그인 상자·로그인 링크(8곳 중 8곳), 해외는 소셜 로그인 단추(Google·Apple·Facebook) 8곳 중 5곳
- 히어로(제목+가입 단추)가 있는 곳: 한국 8곳 중 1곳, 해외 8곳 중 5곳(X·Instagram·LinkedIn·Pinterest·Discord)
- 자동 슬라이드: **16곳 중 0곳**
- 로그인 후 관찰: 0곳

### 커머스 (로그인 전 5곳: 한국 3·해외 2)

- 첫 화면 맨 위에 검색창: 5곳 중 5곳 / 카테고리 진입점(단추·메뉴 줄): 5곳 중 5곳
- 히어로(제목 문장+단추): 5곳 중 0곳
- 자동으로 도는 큰 배너: 한국 3곳 중 3곳(약 2초·3초·3.5~4초), 해외 2곳 중 0곳
- 해외 2곳은 멈춘 카드 격자·편집 배너
- 로그인 후 관찰: 0곳

### 콘텐츠·미디어 (6곳: 한국 3·해외 3, 로그인 전 5·후 1)

- 맨 위가 편집형 격자: 6곳 중 4곳(네이버 뉴스·NYT·브런치·티빙 큰 배너) / 개인화 추천: 1곳(YouTube, 로그인 후) / 가입 랜딩: 1곳(Medium) / 검색·카테고리가 맨 위: 0곳
- 히어로(제목+단추): 6곳 중 1곳(Medium)
- 자동으로 도는 큰 배너: 6곳 중 1곳(티빙, 약 5초). 작은 띠 배너가 도는 곳 1곳(브런치, 약 10초)

### 마켓플레이스·O2O (로그인 전 7곳: 한국 3·해외 4)

- 맨 위가 위치·날짜 입력: 7곳 중 5곳 (여기어때·Airbnb·Booking·Zillow·DoorDash) / 카테고리: 1곳(직방) / 검색+카테고리: 1곳(당근)
- 제목 문장이 있는 첫 화면: 7곳 중 5곳 (그중 사진 배경 4곳)
- 자동으로 도는 큰 배너: 7곳 중 0곳 (검색 줄 아래 이벤트 카드 줄이 도는 곳 1곳)
- 첫 방문 팝업: 7곳 중 2곳(Airbnb·Booking, 둘 다 로그인하면 할인)
- 로그인 후 관찰: 0곳

## 5. 규칙 후보

### 5.1 가설 판정

| 가설 | 판정 | 근거 수치 |
|---|---|---|
| ① SaaS 홈은 광고 랜딩을 겸해 히어로가 있는 정형화된 섹션 구성이다 | **확인** | 히어로 16곳 중 16곳. 차례는 「히어로 → (로고 띠) → 기능 설명 여러 개 → 고객 사례·성과 → 최종 행동 유도 → 푸터」가 대부분이고, 최종 행동 유도 16곳 중 14곳. 단 가격표·FAQ는 홈 본문에 **0곳** — 흔히 떠올리는 「가격·FAQ까지 있는 랜딩」은 아니었습니다. |
| ② 커머스 홈은 카테고리·검색과 슬라이드형 추천 상품이 주를 이룬다 | **부분 확인** | 검색 5곳 중 5곳, 카테고리 5곳 중 5곳. 도는 큰 배너는 한국 3곳 중 3곳이지만 해외 2곳 중 0곳. 도는 것은 대부분 기획전 배너이고 「추천 상품」 자체가 도는 곳은 없었습니다. 표본 5곳이라 해외 쪽은 판정이 약합니다. |
| ③-a 커뮤니티·SNS는 로그인하면 히어로가 없다 | **판정 불가** | 커뮤니티·SNS 로그인 후 관찰 0곳. 다른 유형 로그인 후 2곳(YouTube·Vercel)과 참고 1곳(GitHub)은 모두 히어로가 없었습니다. |
| ③-b 해외는 로그인 전에 가입 유도 랜딩이 있다 | **확인** | 가입을 먼저 요구하는 화면 8곳 중 6곳 + 콘텐츠 옆 가입 패널 1곳 = 7곳. 가입 요구 없이 목록만 보인 곳 1곳(Stack Overflow). 단 6곳 중 3곳은 스크롤 섹션이 있는 랜딩이 아니라 한 화면짜리 로그인·가입 창이었습니다. |
| ③-c 한국은 랜딩 없이 편집형 섹션이나 필터·정렬 목록형이 대부분이다 | **확인** | 콘텐츠가 바로 보이는 곳 8곳 중 7곳(편집형 5·목록형 1·허브형 1). 예외 1곳(밴드)은 가입 랜딩이었습니다. |
| ④ 콘텐츠·미디어를 별도 유형으로 둘 근거가 있나 | **약함 — 판정 보류** | 뉴스·글 3곳은 편집형 격자로 한국 커뮤니티 편집형과 구성이 비슷하고, 영상 스트리밍(티빙)은 도는 큰 배너+바로가기 줄로 한국 커머스와 비슷했습니다. 6곳 안에서도 갈라져 하나의 유형으로 묶이지 않았습니다. |
| ⑤ 마켓플레이스·O2O를 별도 유형으로 둘 근거가 있나 | **있음** | 맨 위가 위치·날짜 입력 7곳 중 5곳 — 커머스는 0곳(자유 검색어 5곳 중 5곳). 제목 문장이 있는 첫 화면 7곳 중 5곳 — 커머스 0곳. 도는 큰 배너 7곳 중 0곳 — 한국 커머스 3곳 중 3곳. |

### 5.2 관찰에서 바로 나오는 규칙

- [ ] **SaaS의 로그인 전 홈은 히어로로 시작합니다.** 16곳 중 16곳이었고, 제목(16/16)·부제(15/16)·행동 단추(14/16)를 갖췄습니다. [실측]
- [ ] **SaaS 히어로는 넘기지 않습니다.** 여러 장을 넘기는 히어로는 16곳 중 0곳이었어요. 움직임이 필요하면 제품 영상(16곳 중 6곳)으로 줍니다. [실측]
- [ ] **SaaS 히어로의 시각물은 제품 화면이 기본값입니다.** 16곳 중 10곳이 실제 제품 화면(이미지·영상)이었습니다. [실측]
- [ ] **SaaS 히어로 단추는 주 1개 + 보조 1개가 흔합니다.** 16곳 중 10곳. 주 단추는 「무료로 시작」 계열(10곳), 보조는 「데모·도입 문의」 계열이 많았습니다. [실측]
- [ ] **SaaS 홈에 가격표·FAQ 섹션을 넣지 않아도 됩니다.** 16곳 중 0곳이었고, 가격은 상단 바 링크로 따로 뺐습니다(15곳). [실측]
- [ ] **SaaS 홈은 최종 행동 유도 섹션으로 끝냅니다.** 푸터 바로 앞에 한 번 더 단추를 둔 곳이 16곳 중 14곳이었습니다. [실측]
- [ ] **로그인한 사람에게는 히어로를 보여주지 않습니다.** 로그인 후 본 곳 모두(2곳 + 참고 1곳) 히어로 대신 작업 화면(대시보드·개인화 목록)이 떴습니다. 표본이 적어 후보로만 둡니다. [실측]
- [ ] **커뮤니티 홈의 로그인 전 화면은 지역에 따라 갈립니다** — 한국은 콘텐츠부터(8곳 중 7곳), 해외는 가입부터(8곳 중 7곳). 우리 서비스가 어느 쪽인지 화면 인벤토리에 적습니다. [실측]
- [ ] **커뮤니티에는 자동으로 도는 배너를 두지 않습니다.** 이번에도 16곳 중 0곳이었습니다(기존 §1의 18곳 중 0곳과 같음). [실측]
- [ ] **커머스 첫 화면 맨 위는 검색과 카테고리입니다.** 5곳 중 5곳. 히어로 문장은 0곳이었습니다. [실측]
- [ ] **위치·날짜로 찾는 서비스(O2O)는 맨 위에 조건 입력 줄을 둡니다.** 7곳 중 5곳 — 자유 검색창 하나만 두는 커머스와 다릅니다. [실측]
- [ ] **O2O 첫 화면은 제목 한 줄 + 조건 입력 줄을 사진 위에 얹는 구성이 흔합니다.** 제목 문장 7곳 중 5곳, 사진 배경 4곳. 큰 배너를 돌리지 않았습니다(0곳). [실측]

## 6. 판정 못한 것

- **모바일 첫 화면** — 51곳 모두 미관찰입니다(도구가 창 크기를 못 바꿈). 모바일에서 히어로·배너·검색 줄이 어떻게 줄어드는지는 이번 자료로 말할 수 없습니다.
- **커뮤니티·SNS 로그인 후 화면** — 0곳. 가설 ③-a는 판정하지 못했습니다.
- **커머스·O2O 로그인 후 차이** — 0곳.
- **로그인 전후 비교** — 같은 서비스의 전과 후를 둘 다 본 곳이 한 곳도 없습니다. 로그인 후 3곳은 모두 로그인 전 화면을 못 봤습니다.
- **커머스 배너 간격** — 이번 한국 3곳은 약 2~4초로, 기존 §1 실측(한국 7~9초)과 다릅니다. 표본·측정 방법(이번은 캡처 간격 약 1.1초)이 달라 어느 쪽이 대표값인지 판정하지 못했습니다.
- **해외 커머스** — 2곳(Amazon·Etsy)뿐이라 「해외는 배너를 안 돌린다」로 일반화하기 어렵습니다.
- **콘텐츠·미디어 유형** — 뉴스·글과 영상 스트리밍이 서로 다르게 나와 6곳으로는 한 유형으로 묶을지, 나눌지 정하지 못했습니다.
- **SaaS 주 단추 문구의 지역 차이** — 히어로·상단 바의 「도입 문의·데모」 비중이 한국과 해외 모두 높아(상단 바 한국 5/8·해외 8/8) 뚜렷한 차이로 보기 어렵습니다.
- **SaaS 첫 화면 사회적 증거** — 16곳 중 6곳으로 갈렸습니다. 로고 띠를 첫 화면에 넣을지는 관례라 부를 만큼 모이지 않았습니다.

## 7. 스킬 반영 제안

- §1 머리말: 실측 범위를 「37곳」에서 이번 51곳을 더한 값으로 바꾸고, 「SaaS는 한 곳도 보지 않았습니다」 문장 삭제. 모바일 미관찰을 한계로 추가
- §1.1 표: SaaS 행의 근거를 「미관찰 — 전제」에서 「16곳 관찰」로 바꾸고 차례 칸을 「히어로 → (로고 띠) → 기능 → 고객 사례 → 최종 행동 유도」로 채움
- §1.1 표: 「마켓플레이스·O2O」 행 추가 (최상단 = 조건 입력 줄)
- §1.1 표: 「커머스·마켓플레이스」 행 이름에서 「마켓플레이스」를 빼거나 O2O와의 경계를 한 줄로 적음
- §1.1 표: 콘텐츠·미디어는 행을 추가하지 않고 「판정 보류」 메모만 둠 (또는 뉴스=편집형, 스트리밍=커머스형 참조)
- §1.1 표: SNS 피드 행을 「로그인 전(가입 화면·랜딩) / 로그인 후(피드)」로 나눌지 검토 — 로그인 후 표본 확보 후
- §1.2: 「최상단 1·2번은 탐색 진입점」 규칙에 SaaS·O2O 예외(SaaS는 히어로, O2O는 조건 입력 줄) 명시
- §1.2: SaaS 규칙 추가 — 히어로 필수, 히어로 넘기지 않음, 시각물은 제품 화면, 주+보조 단추, 가격·FAQ 없음, 최종 행동 유도
- §1.2: 로그인 후 히어로 제거 규칙을 후보로 추가 (표본 적음 표시)
- §1.2: 커뮤니티 로그인 전 화면의 지역 차이(한국 콘텐츠 먼저 / 해외 가입 먼저) 추가
- §1.2: 커머스 배너 간격 수치를 이번 값과 함께 범위로 고치거나 「재측정 필요」 표시
- §1.3: 「로그인 전후 홈을 다르게 둘지」 결정 항목 추가
- §1.3: 커뮤니티라면 「로그인 전에 콘텐츠를 먼저 보여줄지, 가입부터 받을지」 결정 항목 추가
- §1.3: SaaS라면 「히어로 주 단추를 무료 시작으로 할지, 도입 문의로 할지」 결정 항목 추가
