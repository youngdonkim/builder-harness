### 확신 없어 뺀 것

- 「하네스가 막고」(94·117행), 「하네스가 에이전트를 끊는다」(106·129행): 이 저장소에서 「하네스」는 builder-harness를 뜻하는데 여기선 Claude Code 실행 환경을 가리켜 뜻이 둘로 읽힌다. 실측 문장이라 낱말만 바꾸는 것도 사람이 볼 일. 바꾼다면 「Claude Code가」.
- 「파일 수가 아니라 게시 횟수로 센다」·「하나 쓰고 하나 보내라」 인용·`dc-import`: 바깥 도구 사실이라 판정 안 함. 타입 안내가 바뀌면 인용이 낡을 수 있다.
- `_progress.md`·`design-prompt.md`가 게시 때 같이 올라가는지: 바깥 사실.
- 끊긴 뒤 이어 하는 것이 「자율 재작업 최대 2회」에 드는지: 다시 만드는 게 아니라 이어서 하는 거라 충돌 아님으로 봄.
- 첫날 193장과 200번의 차이: 「게시 횟수 ≠ 장 수」와 맞아 손대지 않음.
- 5단계 안 미커밋 이유 세 번(§2.2 1번 / §2.5.6 / §4), SKILL.md §3 캔버스 폴더 ↔ 2단계 §4.2·5단계 §2.2: § 참조로 이어져 있고 층이 달라 B로 안 올림.
